# Food Delivery - Online Food Ordering

A modern food delivery web application built with MERN stack.

## 🚀 Live Demo
- **User Panel:** https://food-delivery-frontend-s2l9.onrender.com/
- **Main Website:** http://localhost:5173

## ✨ Features

### For Users
- User Registration & Login
- Browse Food Menu
- Add to Cart
- Place Orders
- Secure Payments

### For Admin  
- Manage Products
- Manage Orders
- User Management

### Technical Features
- Secure Authentication
- Responsive Design
- REST API
- Real-time Updates

## 🛠️ Technology Stack

**Frontend:** React.js, CSS3  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT
