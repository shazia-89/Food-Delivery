# Food Delivery - Online Food Ordering

A modern food delivery web application built with MERN stack.

## Features

### For Users
- User Registration & Login
- Browse Food Menu  
- Add to Cart
- Place Orders
- Secure Payments

### For Admin
- Manage Products
- Manage Orders
- User Management

## Technology Stack

**Frontend:** React.js, CSS3  
**Backend:** Node.js, Express.js  
**Database:** MongoDB  
**Authentication:** JWT
